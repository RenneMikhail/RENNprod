# RENN Prod

Единый репозиторий трёх частей проекта: сайт, внутренняя панель и регистрация/подбор команды.

## Структура

- `src/shooting-landing/` — исходники сайта и локальный приём заявок.
- `src/crm-prototype/` — панель и адаптер локального реестра.
- `src/team-routing/` — Python/SQLite, Telegram-анкета и логика подбора.
- `docs/` — публичный мобильный просмотр без базы, секретов и реальных отправок.
- `assets/brand/` — векторный логотип.

GitHub Pages публикует только `docs/`. Это демо, не production CRM. Существующий ранний сайт сохранён в корневых файлах и истории Git.

## Локальная работа

Python 3.11+. В `src/team-routing`: `python3 control.py start`. Backend слушает только loopback. Для приватных страниц добавлены учётные записи и серверные роли: `/login`, `auth.py create-user`. Аккаунты создаются владельцем локально; инструкция — `src/team-routing/AUTH.md`. Локальный CSRF-заголовок используется дополнительно к cookie-сессии. Не открывайте этот сервер в интернет. Для токена используйте внешний `.env` через `RENN_PROD_ENV_FILE`; секреты не хранить в репозитории. Runtime база создаётся заново, действующие анкеты из старого проекта не переносятся автоматически.

## Приватность

Нельзя коммитить `.env`, `data/`, SQLite, контакты, логи, частные архивы. Публичные анкеты и заявки — только локальные демочерновики. Доставка предложений/email и удалённое размещение backend с HTTPS ещё требуют отдельного этапа.
