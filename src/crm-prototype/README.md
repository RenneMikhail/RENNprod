# RENN Prod — локальный визуальный прототип

Все люди и проекты демонстрационные. Автономные HTML/CSS/JS без сторонних запросов, шрифтов, CDN и зависимостей.

Открыть index.html напрямую или запустить из этой папки:

```sh
python3 -B -m http.server 8767 --bind 127.0.0.1 --directory .
```

Затем http://127.0.0.1:8767. Корень RENN Prod не обслуживается.

Работают три раздела, поиск, фильтры, карточка, смена ответственного и этапа, два срока с проверкой порядка, проверка владельцем, внутренние заметки, подбор и подтверждение исполнителя. Состояние сохраняется в localStorage этого браузера. Сброс в боковом меню и внизу карточки. На мобильном — через карточку. Ввод экранируется перед отображением. Никакой авторизации, backend, отправки, реального подтверждения исполнителя или медиа-плеера нет. Смена ответственного лишь фиксирует локальную запись; реального клиента о передаче контакта не уведомляет.

Референсы: [Linear Inbox](https://linear.app/docs/inbox) — очередь внимания и контекст заказа; [Frame.io Review & Approval](https://frame.io/features/review-and-approval) — версия, внутренние замечания и решение о показе. Собственный минимальный дизайн, системные шрифты, декоративные CSS-миниатюры. Обе официальные страницы изучены 25.10.2026.

Тема: графит, сатинированные поверхности, мандариновый акцент, системный monospace. Локальные токены: --rp-bg, --rp-surface, --rp-text, --rp-accent, --rp-border, --rp-font. Между подпроектами тема пока НЕ синхронизирована.

## Подготовка реестра специалистов

team-api-adapter.js — отключённый ES-module адаптер. UI сейчас использует только явно демонстрационных людей. Для подключения нужны подтверждённые baseUrl, path, схема ответа и CORS со стороны src/team-routing. Не предполагается конкретный endpoint. Передать mapResponse, возвращающий массив {id:string,name:string,role:string}, затем отрисовывать через textContent/экранирование. Только http://127.0.0.1; без токенов бота, poller и backend в этой папке. Изменять team-routing адаптер не требует.

RU/EN: переключатель в шапке, словарь UI в locales.js, адаптер в i18n.js; бизнес-логика не дублируется. EN покрывает основную навигацию и управление заказом; исходные демо-названия, люди, сообщения/заметки и некоторые пояснения остаются по-русски. Это основа локализации, не полный международный релиз. Цены в RUB не меняются. ES/FR не реализованы.


## Реальная локальная интеграция — 25.10.2026

Эта секция заменяет прежнее описание отключённого адаптера.
Рабочая CRM: http://127.0.0.1:8766/crm — обслуживается whitelist-маршрутами server.py соседнего team-routing. Его запуск: python3 -B server.py (из team-routing). Основные файлы CRM остаются здесь. Старая автономная версия на 8767 не имеет сессии и показывает отключённый реестр.

Команда → Обновить реестр выполняет same-origin GET /api/specialists с текущим X-Local-Session, внедрённым сервером только в HTML /crm. Сессия не сохраняется в localStorage и не логируется. Токен Telegram не читается и не копируется. После перезапуска сервера страницу нужно перезагрузить.

SQLite-анкеты отображаются отдельно от seeded демо-записей. Имена с явным префиксом TEST/ТЕСТ дополнительно помечаются как тестовые анкеты. В исходном контракте нет отдельного поля происхождения demo/test; seed определяется по сочетанию «Демо ·» и email @example.invalid, тест — по явному префиксу. Для production нужен серверный флаг provenance.

Показаны только имя, роль, город, источник и статус квалификации. Контакты, Telegram ID и ставки не отображаются. Исходный owner-only API возвращает более широкую запись; эта локальная сессия не является production auth/ACL. Заказы и действия с заказами в этой CRM по-прежнему демонстрационные и не записываются в SQLite. Сброс демо не удаляет анкеты из базы.

Ссылка «База и подбор» открывает /panel на том же локальном сервере. Нет новых poller, копии токена, публичной публикации или монтажа корня проекта. Whitelist отдаёт лишь HTML, CSS и четыре JS-файла CRM; README, QA, .env, data и архив не обслуживаются.
