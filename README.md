# RENN Prod

Единый репозиторий трёх частей проекта: сайт, внутренняя панель и регистрация/подбор команды.

## Структура

- `src/shooting-landing/` — исходники сайта и локальный приём заявок.
- `src/crm-prototype/` — панель и адаптер локального реестра.
- `src/team-routing/` — Python/SQLite, Telegram-анкета и логика подбора.
- `docs/` — публичный мобильный просмотр без базы, секретов и реальных отправок.
- `assets/brand/` — векторный логотип.

GitHub Pages публикует только `docs/`. Это демо, не production CRM. Существующий ранний сайт сохранён в корневых файлах и истории Git.

## Локальная работа

Python 3.11+. В `src/team-routing`: `python3 control.py start`. Backend слушает только loopback. Его локальная сессия не заменяет настоящую авторизацию. Не открывайте этот сервер в интернет. Для токена используйте внешний `.env` через `RENN_PROD_ENV_FILE`; секреты не хранить в репозитории. Runtime база создаётся заново, действующие анкеты из старого проекта не переносятся автоматически.

## Приватность

Нельзя коммитить `.env`, `data/`, SQLite, контакты, логи, частные архивы. Публичные анкеты и заявки — только локальные демочерновики. Доставка предложений/email и защищённый удалённый backend ещё требуют отдельного этапа.
